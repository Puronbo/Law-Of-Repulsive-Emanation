# PREDICTION LEDGER

**Status:** Live. **Purpose:** To make the program's claims falsifiable.

The 0/0 program has a confirmation filter and, until now, no refutation
ledger. Every entry below is a *bet* — a statement that a named quantity
either does not exist (anti-class: no removable value, fluctuations sit on
the denominator) or does exist with a bounded, named value (removable
class). Each bet carries the finite-range evidence in this repository, the
external authority that decides it if any, and the exact condition under
which the bet is lost. A bet that is lost is a finding, not a failure.

Classification, as used below (see `experiments/aclass_detector.py`):

- **A/D-ratio criterion.** A singularity is *removable* (value exists,
  finite) when its fluctuation scale is subleading to the denominator:
  the fluctuation exponent beta of the running-max series satisfies
  `beta < alpha`, with `alpha` the leading denominator exponent.
- **Anti-class.** No removable value exists; the fluctuations sit *on*
  the denominator (`beta ~= alpha`). The Polya/Liouville sum, whose
  fluctuations follow Littlewood's `Omega +- (sqrt(n))`, is the canonical
  verified member (beta = 0.486 over 10 decades, r2 = 0.97).

## Standing rules

1. A ledger entry whose external referee is marked *settled* is kept as a
   permanent calibration point (PL-1, PL-7) — the detector must classify
   it ANTI.
2. Entries with finite-range evidence only are bets that can still be
   lost; losing one is a result to be written up, not erased.
3. New 0/0 experiments enter the ledger before they enter the atlas when
   they carry a named statistic plus a refutation condition. A claim with
   no refutation condition is not a claim.
4. The detector tool (`experiments/aclass_detector.py`, output
   `experiments/data/aclass_detector.json`) is the standard instrument for
   registering the fluctuation exponent of a new entry.
