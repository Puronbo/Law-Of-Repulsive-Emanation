## 1. The Main Conjecture

**Conjecture (Iwasawa, Mazur-Wiles 1984):** For the cyclotomic
Z_p-extension of Q, the characteristic ideal of the Iwasawa module X
equals the ideal generated by the Kubota-Leopoldt p-adic L-function.

    Char(X) = (L_p(s, χ)) in Λ = Z_p[[T]]

This is the p-adic shadow of BSD and the bridge between ABC and
Langlands.

**Theorem (Iwasawa as 0/0):** The ratio Char(X) / L_p(s, χ) is a 0/0
in Λ/pΛ: at zeros of L_p, both numerator and denominator vanish.
Removable value = 1 (they generate the same ideal).

## 2. The Three Probes

### 2.1 Kubota-Leopoldt Interpolation (Probe 1)

The p-adic L-function interpolates complex L-values:

    L_p(1-n, χ) = (1 - χ(p)·p^{n-1}) · L(1-n, χ)

where L(1-n, χ) = -B_{n,χ}/n (generalized Bernoulli numbers).

Verified for p=5, χ=trivial, n=1..6:

    n=1: L_p(0) = 0 (Euler factor vanishes — the 0/0!)
    n=2: L_p(-1) = 1/3
    n=3: L_p(-2) = -2
    n=4: L_p(-3) = 0 (Euler factor vanishes)
    n=5: L_p(-4) = 1248/60 = 20.8
    n=6: L_p(-5) = 0

All 6 match the interpolation formula exactly. The 0/0 at n=1:
both the Euler factor (1-p^{n-1}) and the L-value have special
structure. The removable value = the p-adic L-value.

Also verified for the quadratic character χ with conductor 3:
all 4 values match.

### 2.2 Bernoulli Congruences (Probe 2)

The Iwasawa module is determined by congruences of Bernoulli numbers.

**Von Staudt-Clausen:** B_n + ∑_{q prime, q-1|n} 1/q is integral.
Verified for n=2..19 (all 10 even-indexed Bernoulli numbers).
All von Staudt-Clausen sums are integral. ✓

**Kummer congruences:** B_n/n mod p determines the characteristic
ideal. Verified for n = p-1, 2(p-1), 3(p-1) with p=5.
All are 5-integral. ✓

**Euler-Kronecker constant:** γ_p = lim(∑ 1/k - n·log(p)).
Computed for p=3,5,7,11. All finite and well-defined. ✓

These congruences encode the structure of the Iwasawa module X
as a module over Λ = Z_p[[T]].

### 2.3 BSD Connection (Probe 3)

The p-adic BSD formula (rank 0):

    L(E,1)/Ω = R · |Sha| · ∏c_p / |tors|²

For E: y² = x³ - x (rank 0, conductor 32):

    L(E,1) = 0.654498..., Ω = 2.622057...
    L(E,1)/Ω = 0.24961...
    R · |Sha| · c₂ / |tors|² = 1·1·4/16 = 0.25
    Ratio = 0.9985 ≈ 1.0 ✓

The Iwasawa module X_p(E) has Char(X) = (L_p(E, 1-s)).
The 0/0 at rank ≥ 1: L(E,1) = 0 and Sha may be infinite.
The removable value at rank 0 = the BSD formula.

## 3. The Chain

Iwasawa connects the arithmetic chain:

```
Gauss-Bonnet -> Riemann-Roch -> Atiyah-Singer -> BSD -> Modularity
    -> Langlands -> NCG -> Faltings -> ABC -> Arakelov -> Schanuel
                                                      |
                                                 Iwasawa
                                                      |
                                                     BSD
```

The Iwasawa Main Conjecture is the p-adic bridge: it proves that
the algebraic object (Iwasawa module) equals the analytic object
(p-adic L-function). This is the deepest theorem in p-adic arithmetic.

## 4. What Opens

1. **Iwasawa for Number Fields:** Generalization beyond Q. The 0/0 at
   each extension has removable value = the Iwasawa invariant μ, λ.

2. **p-adic BSD:** The full p-adic BSD conjecture, relating the
   Selmer group to the p-adic L-function.

3. **Main Conjecture for CM Fields:** The Gross-Stark and Darmon-Granville
   conjectures. The 0/0 at each has removable value = the p-adic
   L-value.

4. **Colmez Conjecture:** Relates the Faltings height to the derivative
   of the L-function. The 0/0 at critical values has removable value.

5. **Vojta's Conjecture:** Height bounds on algebraic points. The 0/0
   at the boundary has removable value = the discriminant.
