# Contributing

This project is the formal expression of the Puno Calculus, authored by Michael Grafiel Sayson Puno.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make changes. Ensure all math validation tests pass.
4. Submit a pull request.

## Standards

- All formulas must be validated against `math_validation.py`.
- All engine runs must produce valid JSON output.
- New experiments should follow the pattern in `Universals/exp*.py`.

## Philosophy

The crease is where the action is. The constant is determined.
