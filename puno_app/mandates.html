Text-Mandatable Professions

Which professions can be easily mandated through text — where a complete written instruction set fully determines the work, so an agent handed only the text produces the output with no tacit, embodied, or situational knowledge to supply (Polanyi: we know more than we can tell). Mandate fraction = 1 − skill fraction. Fully (≥90% text-driveable, no gate) is the answer set; gated adds a licensing/attestation duty; partial keeps a live/embodied residue; not is skill-dominated.

Honest walls

  • Mandate is capability in text, not adoption — the gate is exactly where licensure decides who may act on the output.
  • Profession decompositions are stated [hypothesis] estimates, not measurements; edit professions/professions_data.py and every artifact changes at once.
  • Generated mandate texts are templates (the shape of a text spec), not full specification documents.
  • Skill is not permanently tacit: as corpora and teleoperation improve, some partial/not work becomes mandatable. These are current-articulability verdicts.

Method

  • Each profession decomposes into tasks (share, k, s, gate), k+s≤1.
  • K and S are effort-weighted sums; mandate fraction = 1 − S.
  • Status: fully (≥0.90, no gate) · fully-gated (≥0.90, gate) · partial (≥0.50) · not (<0.50).
  • Rubric classes: A = no skill, no gate · B = gated · C = augment · D = skill.
