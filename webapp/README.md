# Sigma: The Removable Singularity Chassis

**No API keys. No dependencies. Self-contained.**

## Quick Start

### Option 1: Open the HTML file directly
```
webapp/sigma.html
```
Double-click to open in any browser. Works offline.

### Option 2: Run the server
```
python sigma_server.py
# Open http://localhost:8000
```

### Option 3: GitHub Pages
1. Push to GitHub
2. Enable Pages (Settings > Pages > Source: main)
3. Your site is live at `https://yourusername.github.io/Law-Of-Repulsive-Emanation/`

### Option 4: Netlify / Vercel
Drag and drop the `webapp/` folder. Zero config.
